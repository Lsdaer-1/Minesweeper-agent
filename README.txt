In this project, we have two training files: agent.py and agent1.py. Agent.py is the original version with a Minesweeper win rate of 20%, while agent1.py is the optimized version achieving a 30% win rate. Simply run the scripts directly; each will take approximately five hours to complete.

plot_ddqn_stats.py generates plots for Average opened cells, Progress ratio, Guess ratio, Win rate, and Episode reward. To run different training versions, change the filename on line 25. We've included files from two completed training runs; simply modify the filename to switch between them.

eval_ddqn_frontier_pygame.py generates the game interface and exports gameplay as GIFs. To modify training results, change the filename on line 19.
